# 💼 IT Inventory Management System  
ระบบจัดการอุปกรณ์ไอที (IT Inventory) สำหรับติดตามสถานะอุปกรณ์ การยืม-คืน และจัดเก็บข้อมูลพนักงาน
## Features   
### 📊 Dashboard  
- แสดงจำนวนอุปกรณ์ทั้งหมดในระบบ
- แสดงสถานะอุปกรณ์ พร้อมใช้งาน, ชำรุด, ถูกยืม
- แสดงรายการยืมล่าสุด พร้อมชื่อผู้ยืม
### 🖥️ จัดการอุปกรณ์
- เพิ่ม / แก้ไข / ลบ อุปกรณ์
- จัดหมวดหมู่อุปกรณ์ (Category)
- ค้นหารายการอุปกรณ์
- Export ข้อมูลอุปกรณ์เป็น Excel
### 🔄 ระบบยืม-คืนอุปกรณ์
- เลือกพนักงานจากรายการ หรือเพิ่มพนักงานใหม่ได้
- บันทึกวันที่ยืม / วันที่คืน
- ค้นหาและเลือกรายการยืม-คืนได้
- เก็บประวัติการยืมของอุปกรณ์แต่ละชิ้น
### 👨‍💼 จัดการพนักงาน
- เพิ่ม / แก้ไข ข้อมูลพนักงาน
- ระบุสาขา และแผนก
### 📜 ประวัติการยืม-คืน
- แสดงรายการยืม-คืนทั้งหมด
-Export ข้อมูลเป็น Excel
### 🔐 ระบบความปลอดภัย
- Login / Logout
- จำกัดสิทธิ์การเข้าถึงข้อมูล
### ✨ แนวคิดในการพัฒนา
- ออกแบบระบบให้สามารถติดตามสถานะอุปกรณ์ได้แบบเรียลไทม์
- ลดความซ้ำซ้อนในการจัดการข้อมูลอุปกรณ์และพนักงาน
- เน้น UI ที่ใช้งานง่ายสำหรับงาน IT Support
- รองรับการ Export ข้อมูลเพื่อใช้งานต่อใน Excel
### 🚀 จุดเด่นของโปรเจค
- รองรับการใช้งานจริงในงาน IT Support
### 🛠️ Tech Stack  
##### Frontend  
- HTML, CSS (Tailwind CSS)
- JavaScript (Vanilla JS)
- UI Libraries: Font Awesome 6, Animate.css, SweetAlert2
##### Backend
- PHP
##### Database
- MySQL
